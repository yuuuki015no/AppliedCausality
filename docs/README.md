# Applied Causality documentation

- [README](../README.md): installation, Provider recipe, first craft, compatibility, and support.
- [Configuration and Installer rules](CONFIG_RULES.md): server config, initial rules, supported configured profiles, and diagnostics.
- [Configuration templates](../examples/config/): copyable common config and initial rule files.
- [Changelog](../CHANGELOG.md): changes to Applied Causality.
- [Building from source](../BUILDING.md): requirements, build/test commands, and release artifacts.
- [LGPL-3.0-or-later License](../LICENSE.txt) and [third-party notices](../NOTICE.txt): original MOD rights, reuse permissions, and upstream license boundaries.

The release JAR includes this index, the README, changelog, build instructions,
license notices, configuration guide, and configuration templates. Open the JAR
as a ZIP archive to read them. Installing the MOD does not require building it.

Corresponding source is published separately on GitHub before each CurseForge
binary release. Follow the CurseForge project's Source link and that file's
version-specific source link to obtain the matching release.
